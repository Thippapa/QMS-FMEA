# QMS-FMEA

Quality Management System (QMS) web application for managing:

- Requirement Reference
- FMEA Dashboard
- Approval tracking
- Control Plan 

Built with Django + SQL Server for manufacturing and quality engineering workflows.

---

# Live Demo: https://qms-fmea.onrender.com

> Note:
> The online demo uses sample/demo data for public portfolio purposes.
> Local development environment connects to SQL Server with real manufacturing data.

---

# Features

## Requirement Reference
- Requirement reference management
- Revision tracking
- Responsible owner tracking
- Requirement detail reference

## Model Dashboard
- FMEA document monitoring
- Model / Component tracking
- Revision management
- Dashboard summary

## Approval Dashboard
- Approval workflow monitoring
- Pending / Approved / Rejected tracking
- Approver monitoring
- Revision tracking

## Control Plan (CP Form)
- Process control management
- Product / Process characteristics
- Inspection frequency
- Reaction plan
- Measurement methods
